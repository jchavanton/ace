API

Machine-callable JSON endpoints for driving ace from scripts and CI. All endpoints share the same HTTP Basic auth as the web UI when -basic-auth-htpasswd is set.

POST /api/scenarios/:name/run

Start a scenario run. Returns 202 Accepted immediately; poll /api/runs/:id for the outcome.

Form parameters (all optional)
NameTypeNotes
sip_portintOverride SIP port (1024-65535). Empty = scenario sidecar → config default.
rtp_startintRTP port range start.
rtp_endintRTP port range end. Must be ≥ rtp_start.
auto_portsboolSet to 1 to let ace pick free SIP/RTP ports. Discards the three fields above.
public_addressstringIP advertised in SIP Contact/Via.
timeout_secondsintHard cap on run duration. 0 = unlimited.
transportenumudp, tcp, or tls. Empty = scenario default.
nameserversstringComma-separated DNS resolver list.
Response 202
{
  "id": "20261026-153740-aizan_test_option4",
  "url": "/runs/20261026-153740-aizan_test_option4"
}
Errors
  • 404 — scenario not found
  • 400 — invalid port/IP/timeout/transport input
  • 409 — runner refused (overlapping ports, concurrency limit)
Example
curl -u user:pass -X POST \
  -d 'auto_ports=1' \
  http://host:8086/api/scenarios/aizan_test_option4/run
GET /api/runs/:id

Poll a run's status. passed is null while running; true/false once complete.

Response 200
{
  "passed": true,
  "run": {
    "id": "20261026-153740-aizan_test_option4",
    "scenario": "aizan_test_option4",
    "status": "passed",
    "started_at": "2026-10-26T15:37:40Z",
    "ended_at":   "2026-10-26T15:38:12Z",
    "started_by": "julien",
    ...
  }
}
Errors
  • 404 — run id unknown
Example (poll until done)
while :; do
  r=$(curl -s -u user:pass http://host:8086/api/runs/$ID)
  echo "$r" | jq -e '.passed != null' >/dev/null && break
  sleep 2
done
echo "$r" | jq .passed
GET /api/metrics/range

Proxy to Prometheus query_range. Server-side selects the PromQL based on the panel name from an allowlist — clients do not pass raw queries. Powers both the bot report and /monitoring pages.

Query parameters
NameRequiredNotes
panelyesPanel name. Bot panels: runs_rate, calls_rate, invite_p95, mos_rx, rtt_avg. Host panels: host_cpu, host_mem, host_disk, host_load1, host_net.
started_bybot panels onlyLabel value — typically bot:<name>. Required for bot panels; must be omitted for host panels.
range_minnoRange in minutes, default 1440 (24h), max 129600 (90d). The handler derives start, end, and an adaptive step (floored at 15s, ceilinged at 1h).
Response
{
  "panel": "host_cpu",
  "step":  15,
  "result": [ /* Prometheus matrix: [{ metric:{...}, values:[[ts,"v"], ...] }, ...] */ ]
}
Errors
  • 400 — unknown panel, or missing/empty started_by on a bot panel
  • 502 — Prometheus unreachable or returned a non-success status
  • 503 — -prometheus-url not configured on this ace instance
Examples
# Bot panel (per-bot filter required)
curl -u user:pass \
  'http://host:8086/api/metrics/range?panel=runs_rate&started_by=bot:my-bot&range_min=1440'

# Host panel (global, no started_by)
curl -u user:pass \
  'http://host:8086/api/metrics/range?panel=host_cpu&range_min=60'
Authentication

When basic auth is enabled, every /api/* request requires an Authorization: Basic … header. Users are managed in the ansible inventory (ace_basic_auth_users), stored bcrypt-hashed in htpasswd, and reloaded every 10s so a playbook re-run adds a user with no restart.
